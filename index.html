核心功能

📱

设备管理

支持多设备连接管理，自动检测已连接设备，提供设备信息查询和状态监控

🎯

UI自动化

支持多种元素定位方式（text、resourceId、xpath），实现点击、输入、滑动等操作

📦

应用管理

一键启动、停止应用，获取当前运行应用信息，管理应用生命周期

🔍

OCR识别

基于PaddleOCR的文字识别，支持屏幕文字提取、文本定位和点击

💻

ADB命令

执行任意ADB shell命令，获取设备命令执行结果，支持设备底层操作

📷

截图功能

实时获取设备屏幕截图，便于测试验证和问题排查，支持图片保存

快速开始

简单几步，即可开始使用

安装依赖
# 安装依赖
pip install -e .

# 启动MCP服务
python src/server.py
Python客户端示例
# Python客户端示例
import mcp_android as mcp

# 初始化设备连接
mcp.init_uiautomator2()

# 启动小红书APP
mcp.start_app("com.xingin.xhs")

# 点击搜索图标
mcp.click_element(resourceId="com.xingin.xhs:id/search")

# 输入搜索关键词
mcp.input_text("美食教程")

# 获取屏幕截图
screenshot = mcp.get_screenshot()

# OCR识别屏幕内容
result = mcp.ocr_screen()
